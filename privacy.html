Privacy policy

Job Autopilot is a personal tool used only by its owner, on the owner's own computer.

Google data it accesses

  • Google Drive (drive.file): only the folder and cover-letter documents the tool itself creates.
  • Google Sheets (spreadsheets): this permission allows reading and editing every spreadsheet in the account. The tool only opens the tracker spreadsheet it created.
  • Gmail (read) (gmail.readonly): this permission allows reading all mail. The tool only searches recent messages sent by job-application systems (Greenhouse, Lever, Ashby) for verification codes.
  • Gmail (send) (gmail.send): one summary email a day, sent from the owner's account to the owner and the job candidate.

Storage and sharing

Data stays in the owner's Google account and on the owner's computer. Nothing is sold, shared with third parties, or used for advertising. Google user data is not used to train AI models. Job-posting text and the candidate's resume may be sent to the Anthropic API to draft cover letters; no Gmail content is sent.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
